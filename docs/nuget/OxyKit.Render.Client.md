# OxyKit.Render.Client

Typed HttpClient SDK for the [OxyKit.Render](https://oxykit.dev/render/) document render engine (`net10.0`).

```bash
dotnet add package OxyKit.Render.Client
```

Pulls in `OxyKit.Render.Contracts` transitively. Do **not** reference `OxyKit.Render.Core` — it is host-internal and not published.

**.NET Framework 2.0 / 4.5+:** use raw HTTP — see [Framework integration](https://oxykit.dev/integrate/framework).

Docs: [oxykit.dev](https://oxykit.dev) · Source: [oxykit-dev/OxyKit.Render](https://github.com/oxykit-dev/OxyKit.Render)
