# OxyKit.Render.Contracts

Shared request/response DTOs for OxyKit.Render Local (and suite consumers).

Integrators normally take [`OxyKit.Render.Client`](https://www.nuget.org/packages/OxyKit.Render.Client) only; this package is pulled in transitively.

Docs: [oxykit.dev](https://oxykit.dev) · Source: [oxykit-dev/OxyKit.Render](https://github.com/oxykit-dev/OxyKit.Render)
